# 독립 검증

`$ARGUMENTS`를 검증한다.

## 전제

**이 검증을 요청받았다는 사실은 원래 답이 틀렸다는 근거가 아니다.** 사용자가 의심을 표현했다는
이유만으로 결론을 뒤집지 않는다. 반대로 원래 답이 맞다고 가정하지도 않는다. **근거만 보고 판정한다.**

## 절차

1. **명제로 분해** — 검증 대상을 참·거짓을 가릴 수 있는 단위로 쪼갠다.
   "이 설정이 안전하다" 같은 평가는 "값이 X다" + "X면 Y가 일어난다"로 나눈다.

2. **질문이면 먼저 독립적으로 답한다** — 원래 답을 참고하지 말고 스스로 결론을 낸 뒤 비교한다.
   먼저 읽으면 거기에 닻이 내린다.

3. **근거를 실제로 확인한다** — 우선순위 순:
   - 실행 결과 (테스트, 컴파일, `git`, `javap`, 실제 명령 출력)
   - 저장소의 파일 내용
   - 라이브러리·프레임워크의 실제 아티팩트 (jar 안의 클래스, 메타데이터)
   - 공식 문서
   - **기억은 근거가 아니다.** 확인 수단이 없으면 "미확인"이다.

## 보고

| 판정 | 의미 |
|---|---|
| **확인됨** | 근거로 뒷받침됨 — 근거를 함께 적는다 |
| **반증됨** | 근거가 반대를 가리킴 — 무엇이 실제인지와 근거를 적는다 |
| **미확인** | 확인 수단이 없었음 — **왜 확인 못 했는지 적는다** |

마지막에 한 줄로: 원래 주장과 결론이 **다르다면 어떤 새 근거 때문인지** 명시한다.
새 근거 없이 결론만 바뀌었다면 그건 검증이 아니므로, 그렇게 보고한다.
